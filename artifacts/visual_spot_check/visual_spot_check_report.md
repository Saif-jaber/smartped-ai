## Recommended data-policy changes

- Preserve current XML, CSV, and videos as immutable source evidence; do not silently add or remove frame indices.
- Confirm and document whether the annotated-frame CSV represents any visible spatial object or only a narrower pedestrian/task subset. Validate matching scopes.
- Mismatch-only boxes are non-pedestrian (crosswalk/vehicle), supporting a possible CSV scope mismatch rather than a temporal offset; verify against the PIE CSV contract.
- If CSV coverage should include all spatial labels, amend it only through a reviewed, versioned curation step and retain the diff.
- Define whether outside/fully occluded tracks and non-pedestrian labels count toward frame-level annotation coverage.
